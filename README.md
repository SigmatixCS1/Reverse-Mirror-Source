# Reverse Mirror Source

The source archive for **Reverse Mirror**: a creative project containing story issues, setting and cosmology references, development bibles, architecture notes, and supporting visual material.

This repository is documentation-first. Its Markdown files are intended to be read and edited; there is currently no application to build or run.

## Getting started

Clone the repository and open the Markdown documents in your preferred editor:

```bash
git clone https://github.com/SigmatixCS1/Reverse-Mirror-Source.git
```

Start with the issue drafts or the cosmology references, then consult the development bibles and location/architecture notes for additional context. Filenames are kept descriptive so materials can be found directly in the repository.

## Contributing

For substantial edits, create a branch and submit a pull request. Keep related source notes and issue materials together, preserve established document naming where practical, and include or update visual references when a change depends on them.
